# Raman 매핑 기반 공정/수율 분석 로직

UV 나노초 레이저 결정화 single-shot Raman 맵 데이터로부터 반도체 공정 분석 방식의 정량 지표를 산출하는 로직 정리.

## 1. 기본 신호 정의

각 측정점(픽셀)마다 despike 처리된 밴드 적분값 두 개를 사용:

- `Ic` : c-Si 밴드(510~530 cm⁻¹) 내 trapz 적분 면적
- `Ia` : a-Si 밴드(480~490 cm⁻¹) 내 trapz 적분 면적

이로부터 두 파생값을 정의:

```
φ   = Ic / (Ic + Ia)      # 결정질 신호가 차지하는 비율 (0~1, α 무관)
Tot = Ic + Ia              # 총신호 세기 (그 픽셀에 신호가 얼마나 세게 잡혔는가)
```

φ는 Xc(=Ic/(Ic+α·Ia))에서 α=1로 고정한 버전과 같으며, 문헌마다 편차가 큰 보정계수 α 없이 쓸 수 있는 순수 비율.

## 2. Zone 분류 (2단계 판정)

신호 세기 판정과 상(phase) 판정을 독립된 단계로 분리. (하나의 임계값으로 같이 판정하면 φ가 중간값인 경계 지점이 "신호 손실"로 오분류되는 문제가 있었음.)

**1단계 — 신호 유효성**

```
if Tot < signal_floor:
    zone = Signal Loss   # φ 값과 무관하게 즉시 확정
```

`signal_floor`는 사용자가 지정(기본 2%, 통계적 이상치 개념). Otsu 자동화는 φ 히스토그램에만 적용하고 신호 임계에는 적용하지 않음 — 총신호 분포가 실제로 이중분포가 아닌 경우 Otsu가 억지로 큰 덩어리를 손실로 잘라내는 부작용이 있었기 때문.

**2단계 — 상 분류** (신호가 유효한 픽셀만 대상)

```
if φ ≥ φ_hi:        zone = Crystallized
elif φ ≥ φ_lo:       zone = Partial
else:                zone = Amorphous
```

`φ_lo`, `φ_hi`는 듀얼 슬라이더로 조절. Otsu 버튼은 φ 히스토그램에서 두 그룹이 갈라지는 지점을 찾아 φ_hi를 자동 설정(φ_lo = φ_hi/2).

## 3. 상관 분석 — Spearman ρ

Ic와 Ia가 순수 상변화(a→c)로만 설명되는지 확인하는 진단 지표.

```
ρ = Pearson(rank(Ic), rank(Ia))
```

Pearson이 아닌 Spearman을 쓰는 이유: Ic-Ia 관계가 선형이라는 물리적 근거가 없고(산란 단면적 차이, 포화 효과 등), 값이 아닌 순위 기반이라 단조적 반비례 관계면 곡선이어도 정확히 잡아냄.

- ρ < -0.5 : 강한 음의 상관 → 순수 상변화 지배적
- -0.5 ≤ ρ < -0.2 : 중간 수준 → 두께 변화·거칠기 등 혼재 가능성
- ρ ≥ -0.2 : 약함 → 단순 상변화로 설명 불가, 신호 손실 의심

## 4. 반경 프로파일 & 교차 반경

단일 샷 가우시안 빔은 중심(고플루언스) → 가장자리(저플루언스)로 가는 방향성이 있어, 반경 방향 평균이 곧 "받은 에너지량에 따른 반응"을 나타낸다는 전제.

1. 중심점 결정: Ic 강도중심(가중 평균) 또는 스캔 격자 기하중심 중 선택
2. 반경 bin 폭은 고정값이 아니라 **실측 스캔 스텝(dx, dy 중 더 촘촘한 쪽)**을 하한으로, `rMax/40`을 상한으로 자동 산출 → bin 개수(NB)는 이 폭으로부터 역산
3. 각 bin 내 Ic, Ia, Xc 평균
4. Ic, Ia는 각각 자기 최댓값 대비 0~1로 정규화(모양 비교 목적, Xc는 정의상 이미 0~1이라 별도 축에 얹음)
5. 정규화된 Ic 곡선과 Ia 곡선이 교차하는 반경(`rCross`)을 선형보간으로 계산 → 결정질/비정질 우세가 뒤바뀌는 대표 반경

## 5. 임계 플루언스 추정 (가우시안 빔 모델)

```
F(r) = F0 · exp(-2r² / w²)
```

- `F0` : 피크 플루언스(빔 중심, 실측값 필요)
- `w`  : 빔 반경, 1/e² 정의(빔 프로파일러 실측값 필요, 가공 흔적 반경과 다름)

`rCross`를 위 식에 대입하면 그 반경에서의 실제 에너지 밀도, 즉 **결정화 임계 플루언스 추정치**가 나옴. 단일 조건 한 번의 촬영으로 플루언스 스윕 실험을 대체하는 효과.

한계: F0, w가 실측값이 아니면 숫자 자체가 무의미. 빔이 완벽한 단일모드 가우시안이라는 가정도 전제.

## 6. 수율/공정능력 지표

| 지표 | 계산 | 반도체 공정에서의 의미 |
|---|---|---|
| In-spec 비율 | `count(Xc ≥ spec) / N × 100` | 스펙 하한(`spec`, 사용자 지정)을 만족하는 픽셀 비율. 합격품 비율 개념 |
| 균일도 CV | `σ(Xc) / mean(Xc) × 100` | 낮을수록 공간적으로 균일 |
| Cpk (유사) | `(mean(Xc) - spec) / (3σ(Xc))` | 평균이 스펙 하한에서 얼마나 여유 있게 떨어져 있는지. 1.33 이상을 통상 양산 가능 기준으로 봄 |
| Crystallized 면적 | `count(zone=Crystallized) / N × 100` | 유효 공정 면적 비율 |
| Signal Loss 면적 | `count(zone=Signal Loss) / N × 100` | 어블레이션/거칠기 등 이상 의심 영역 비율 |

## 7. 중요 주의사항 (자소서/보고서 작성 시 반드시 명시)

- 이 지표들은 **시료 1개 맵 내부의 공간 산포**를 재는 것이지, 여러 로트·다이의 합격/불합격을 세는 **실제 fab 수율**과 통계적으로 동일하지 않음
- Cpk도 원래 반복 측정 분포에서 뽑는 지표를 픽셀 분포에 적용한 것이라 엄밀한 의미는 다름
- α(보정계수)는 문헌마다 편차가 커서 Xc 절대값은 신뢰도가 낮음 → φ(=α=1) 또는 상대 비교 위주로 해석 권장
- 임계 플루언스 값은 F0·w 실측 정확도에 전적으로 의존
