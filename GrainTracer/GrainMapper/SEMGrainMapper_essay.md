# SEM 기반 결정립 정량 분석 툴 SEMGrainMapper 개발

## 1. 개발 배경: 측정할 수 없는 조건이 더 많았습니다

UV 나노초 레이저로 a-Si 박막을 결정화하면서 fluence, shot 수, 스캔 방향에 따라 grain size가 어떻게 달라지는지 정량적으로 비교해야 했습니다. 결정립 크기를 가장 정확하게 얻는 방법은 EBSD였지만 외부 분석 의뢰가 필요해 모든 조건을 측정할 수 없었습니다. 반면 SEM 이미지는 모든 조건에 대해 확보되어 있었습니다. 그래서 **SEM 이미지만으로 EBSD와 같은 기준의 grain size 분포를 얻는 것**을 목표로 정했습니다.

## 2. 기존 도구의 한계

| 구분 | 방식 | 한계 |
|---|---|---|
| 수작업 | 경계를 직접 그려 면적 계산 | 이미지당 [N]시간 소요, 분석자마다 결과 차이 |
| ImageJ | 밝기 threshold → watershed → particle 분석 | 경계 옆 glow와 grain 내부 bright spot까지 경계로 인식해 과분할 |
| 기계학습 분할 도구 | 사용자가 라벨링한 데이터로 학습 | 시료와 촬영 조건이 바뀔 때마다 학습 데이터를 다시 만들어야 함 |
| 상용 분석 소프트웨어 | 범용 분할 알고리즘 제공 | 유료 라이선스, 시료 특성에 맞춘 조정 한계 |
| EBSD | 결정 방위로 grain 직접 구분 | 외부 의뢰, 조건 수만큼 비용과 시간 증가 |

범용 도구는 "어떤 이미지든" 처리하도록 설계되어 있어 우리 시료 SEM 이미지의 특징을 활용하지 못했습니다. 저는 **문제를 일반화하기보다 우리 이미지의 신호 형태를 분석해 거기에 맞는 알고리즘을 설계**하는 방향을 택했습니다.

## 3. 개발 과정과 시행착오

### ① 과분할: 경계와 노이즈의 신호 형태 차이에 주목
처음에는 Hessian 기반 라인 검출을 적용했지만, 경계 옆 밝은 glow와 grain 내부 bright spot의 테두리까지 경계로 잡혔습니다. 신호를 분석해 보니 실제 경계는 **양쪽이 모두 밝은 valley**였고, spot 테두리는 **한쪽만 밝은 edge**였습니다. 이 차이에 착안해 경계 법선 방향 양쪽의 밝기를 함께 비교하는 **valley 필터**를 설계했고, spot 테두리 오검출이 대부분 사라졌습니다.

### ② 노이즈: 길이와 연결성으로 필터링
SE 이미지 특유의 점 노이즈가 짧은 가짜 경계를 만들어 grain을 다시 쪼갰습니다. 방향별 **line filter**로 일정 길이 이상 이어진 성분만 남기고, **hysteresis threshold**로 강한 경계에 연결된 약한 경계만 살렸습니다.

### ③ 끊긴 경계: 형상 정보로 보완
경계가 중간에 끊기면 두 grain이 하나로 합쳐졌습니다. distance map의 h-maxima를 seed로 쓰는 **marker 기반 watershed**를 적용해, 경계가 끊겨 있어도 grain 중심을 기준으로 분리되게 했습니다.

### ④ 해상도 의존성: 파라미터를 물리 단위로 재정의
같은 x25k 배율이라도 2560 px 이미지(1.98 nm/px)에 맞춘 파라미터를 1280 px 이미지(3.97 nm/px)에 그대로 쓰면 경계 폭이 2배로 잘못 잡혔습니다. 그래서 **모든 파라미터를 nm 단위로 정의**하고 pixel size에 따라 자동 환산하도록 바꿔 배율과 해상도에 관계없이 같은 기준으로 분석되게 했습니다.

### ⑤ 다른 형태의 경계: Contrast 모드 추가
x10k 이미지 중에는 경계가 선이 아니라 grain 간 명암 차로만 보이는 경우가 있었습니다. 선 검출 방식으로는 잡을 신호 자체가 없었기 때문에, 밝기 gradient 기반 **Contrast 모드**와 가로 **scan-line 노이즈 제거**를 별도로 구현해 이미지 유형에 따라 검출 방식을 선택할 수 있게 했습니다.

## 4. 검증

- **정확도**: 실제 이미지에는 정답이 없기 때문에, 경계 위치를 알고 있는 합성 SEM 이미지를 직접 만들어 검증했습니다. Voronoi 구조에 곡률을 준 grain 105개를 만들고 점 노이즈, glow, bright spot, 희미한 경계를 일부러 넣었습니다. 정답 평균 ECD 403 nm 대비 오차는 **약 2%**였습니다.
- **Scale**: 이미지 하단의 Hitachi 눈금 11개를 자동으로 인식해 pixel size를 계산합니다. x25k 이미지에서 1.98 nm/px로, 배율로 계산한 값과 일치했습니다.
- **속도**: 자동 분할 기준 이미지당 **약 1초**로 줄었습니다.

## 5. 기능과 차별점

- **측정 조건 자동 반영**: scale 자동 인식, nm 기반 파라미터 자동 설정, 데이터 바를 제외한 ROI 자동 지정
- **EBSD 호환 지표**: EBSD와 같은 ECD 정의로 number/area fraction 분포, D10·D50·D90, area-weighted ECD 제공
- **공정 해석용 지표**: x·y 방향 linear intercept 비(Lx/Ly)로 스캔 방향에 따른 결정립 이방성 정량화
- **수동 보정**: 경계 그리기·지우기, grain 분할·병합으로 자동 결과를 바로 보정
- **시각화**: 크기별 color map과 히스토그램 색 연동, 조건별 분포 비교(막대/CDF)
- **재현성**: 분석 파라미터를 결과 CSV에 함께 저장해 같은 이미지·같은 파라미터면 같은 값 보장
- **접근성**: 설치 없이 브라우저에서 실행되는 단일 HTML, Hitachi TIF 원본 직접 지원

## 6. 활용과 의미

완성된 툴로 fluence 조건별 ECD 분포를 같은 축에서 비교하고, Lx/Ly로 스캔 방향 이방성을 정량화하는 데 활용했습니다. 이 과정에서 얻은 가장 큰 배움은 **오검출을 파라미터 조정으로 덮지 않고, 데이터의 물리적 신호 형태에서 원인을 찾아 알고리즘 구조로 해결하는 방식**이었습니다. 이 접근은 공정·계측 데이터에서 이상 신호의 원인을 좁혀 가는 문제 해결에도 그대로 적용할 수 있다고 생각합니다.
