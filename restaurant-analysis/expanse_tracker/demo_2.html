식당 손익 분석 데모

실제 식당 엑셀 정산 양식을 웹으로 재구성한 손익 분석 툴 (반도체 공정·수율 분석 관점 포트폴리오용)

1. 입력 (실제 엑셀 파란 셀 전체 반영)

매출·배달앱 수수료·재료비·인건비·운영비·공과금까지 세부 입력 → 자동 KPI/그래프 계산
월 매출 구조
배달앱 고정 파라미터
배달앱 월간 실적 (파란 입력)
재료비 (식자재·주류·포장재 등)
운영비
공과금
인건비
도메인: 식당 손익 구조 유형: 공정·수율 분석형 대시보드

2. 핵심 손익 지표

총매출 → 플랫폼별 수수료 → 재료비·인건비·고정비 → 순이익까지 전체 플로우 요약

3. 시각화 플롯

비용 구조 Breakdown / 배달앱 수익성 / 시간축 관점 손익 분석

3-1. 비용 구조 Breakdown

재료비·인건비·배달 관련 지출·운영비·공과금·세금

3-2. 재료비 구성

공정 Step 별 Loss 시각화와 유사한 식자재 비용 분해

3-3. 배달앱 수익성

플랫폼별 매출·앱 수수료·실부담 배달비 비교
